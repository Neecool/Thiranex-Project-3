## 🎯 Project Overview

A **Machine Learning model** that detects phishing emails with high accuracy using:
- Text analysis (TF-IDF vectorization)
- URL pattern detection
- Linguistic feature extraction
- Multiple ML algorithms (Random Forest, Logistic Regression, Naive Bayes)

## ✨ Features

- ✅ **Real-time email classification** (Phishing vs Safe)
- ✅ **95%+ detection accuracy**
- ✅ **Feature importance analysis**
- ✅ **Confusion matrix visualization**
- ✅ **Multiple ML models comparison**
- ✅ **Confidence scores for predictions**
- ✅ **Model persistence** (save/load trained model)
